# 圆形按钮与播放条间距修复

参考用户截图的比例，统一圆按钮为约 44pt、屏幕左右边距为 16pt。系统 GlassButtonStyle 自带的内边距已计入图标占位，避免图标宽度不同导致两边圆底不等大。

详情页波形条与顶部按钮共用左右边距；112 根波形线按可用宽度分配，不再因固定宽度撑出右侧。首页歌曲信息条的底部留白从 6pt 增加至 18pt，使它与系统悬浮导航之间留出可见空隙。Apple Music 迷你播放器也同步调整底部留白与边距。

原生截图来自提交 `05444a9aad4af0bd0acbb7799fbcd65802f66975`，Xcode 27.1 / iOS 27.2 / iPhone 17 Pro 模拟器。[构建与原生运行检查通过](https://github.com/ZhaoLegs/vinyl-player/actions/runs/42501668480)。

- [首页截图](vinyl-home-spacing-fixed.png)：圆按钮等大，歌曲信息条与导航分开。
- [详情截图](vinyl-detail-spacing-fixed.png)：按钮与底部播放条左右外沿对齐。

已直接核对截图。尺寸按用户截图比例换算，玻璃描边和阴影有少量视觉外扩。18pt 是布局底部留白，不是对系统导航玻璃可见外沿之间距离的精确承诺。
